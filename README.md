# Gamificação Saint Paul Jr

Painel de pontos dos membros da Saint Paul Jr. É uma página estática, sem instalação
e sem banco de dados.

## Como atualizar os pontos

Abra o arquivo `dados.js` no GitHub, clique no lápis, mude os nomes, áreas e pontos,
e salve com "Commit changes". A Vercel republica o site sozinha em cerca de um minuto.

## Deploy

Site estático. Na Vercel, basta importar o repositório e clicar em Deploy, sem
configurar framework nem comando de build.
